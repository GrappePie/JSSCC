# Local test checklist

1. Load the unpacked extension in Opera or Chrome.
2. Reload `https://grappepie.github.io/JSSCC/`.
3. Confirm `OS Browser Bridge conectado`.
4. Search for `kirby`.
5. If Online Sequencer opens a verification page, complete it in that tab, return to JSSCC, and search again.
6. Confirm cards render with IDs/titles/authors/durations.
7. Confirm `Escuchar chiptune` starts JSSCC playback.
8. Check Popular / Most Notes / Longest and Today / This week / This month / All time.
